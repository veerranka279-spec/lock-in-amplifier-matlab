# Orthogonal Lock-in Amplifier (MATLAB Simulation)

Orthogonal (I/Q) lock-in amplifier simulated in MATLAB with a live GUI to recover signals buried in noise.

## How to run
1. Open `lockin_live_gui.m` in MATLAB
2. Press F5 (Run)
3. Use the sliders to change noise level, phase shift and target frequency
